# 自習教室 配置アプリ（共有接続テスト版）

## この版に含まれる機能
- 配置表、開催枠の作成・編集・削除
- 基本ルール、担当者、テスト日程、校舎設定
- 出勤可能日の登録、担当者別一覧
- 警告、自動割り振り、自動分の確定・取り消し
- CSV出力（Excelで開けます）
- Supabase `app_state` への共有保存とRealtime受信
- PC・スマホ表示

## 重要：この共有接続はテスト専用
この版は、希望された「ログインなしで全員が編集する」方式を試すため、Supabaseの `anon` キーで `app_state` を読み書きします。公開ポリシーを設定すると、URLやキーを知った第三者もデータを読んだり変更したりできる可能性があります。`anon` キーは秘密鍵ではありません。

**実際の職員名・出勤予定・在籍人数などの本番データを入れないでください。** これはアクセス制御ではありません。安全な本番運用には、ログインまたはサーバー側APIでの認可、入力検証、レート制限、監査ログ、バックアップなどが必要です。

## GitHubへのアップロード
リポジトリ `jishuu-classroom-app` の Code 画面で、`Add file` → `Upload files` を選び、次の3ファイルをリポジトリ直下にアップロードして Commit changes します。
- `index.html`
- `README.md`
- `supabase_schema.sql`

## Supabase側の設定（テストプロジェクトのみ）
1. SupabaseのSQL Editorを開く。
2. `supabase_schema.sql` の内容を貼り付けて実行する。
3. Project Settings → API（または Connect）で Project URL と anon / publishable key を確認する。
4. 公開したアプリを開き、設定タブ →「共有データ設定」にURLとanon keyを入力し、「共有データに接続」を押す。
5. 画面上部の表示が「共有モード（ログインなし）」になり、接続メッセージが出ることを確認する。
6. 別ブラウザ／別端末でも同じURLとキーを設定し、テストデータが同期するか確認する。

## Vercelへの公開
GitHubにファイルをアップロードした後、VercelでこのリポジトリをImportします。これは静的HTMLなので、Framework Presetは `Other`、Build CommandとOutput Directoryは空欄（または自動設定のまま）で構いません。Deploy後に表示されたURLで動作を確認します。

## 制限事項
- この版の出力はCSVで、正式な複数シートの `.xlsx` ではありません。
- 自動割り振りは試作ロジックなので、結果を人が確認してください。
- 同時編集が同じ瞬間に行われると、最後に保存した内容が優先される場合があります。
- 共有テーブルはアプリ全体を1つのJSONとして保存するため、複数人の本番利用に適した設計ではありません。
